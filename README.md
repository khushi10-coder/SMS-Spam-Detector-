# 📩 SMS Spam Detector

A Machine Learning project that detects whether a message is **Spam** or **Ham (Not Spam)** using Natural Language Processing (NLP), TF-IDF Vectorization, and a Linear Support Vector Machine (SVM).

---

## 🚀 Features

* Data Cleaning and Preprocessing
* Exploratory Data Analysis (EDA)
* NLP Text Processing
* Stopword Removal
* Stemming using Porter Stemmer
* TF-IDF Vectorization
* Linear SVM Classification
* Streamlit Web Application
* Real-Time Spam Detection

---

## 📊 Dataset Information

* Total Messages: 5169
* Ham Messages: 4516
* Spam Messages: 653

---

## 🛠 Technologies Used

* Python
* Pandas
* NumPy
* NLTK
* Scikit-Learn
* Streamlit
* Pickle

---

## 📈 Model Performance

| Metric    | Score  |
| --------- | ------ |
| Accuracy  | 97.78% |
| Precision | 96.75% |
| Recall    | 86.23% |

Algorithm Used:

* Linear SVM (Support Vector Machine)

Vectorization Technique:

* TF-IDF Vectorizer
